# NNgine

## Getting Started

This library uses `uv` for package management. Please install `uv` through the [command line](https://docs.astral.sh/uv/getting-started/installation/). Then:

```bash
uv bash run start.sh
```

will open up a `fastAPI` server at port 8000. You can configure the available models through `config.toml` in the root of the project.
